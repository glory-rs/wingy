# Wingy 0.31.1

Coordinated windowing release for Glory and Sapid 0.6.1.

- Requires Rust 1.95 and uses Cargo workspace resolver 3.
- Publishes the Wingy facade, core, common and platform crates at 0.31.1, and
  the independently versioned `wingy-dpi` support crate at 0.1.3.
- Updates compatible platform dependencies while retaining Android Activity
  lifetime and text-input handling, AppKit and UIKit window integration, and
  the maintained event-loop and resource lifecycle fixes.
- Preserves upstream history, licenses and real README/license file contents
  in the published archives.

Windows, Linux, AppKit/UIKit, Android NativeActivity/GameActivity, Web and Redox
validation remain required in the release workflow. Compilation and protocol
tests do not establish physical-device IME or screen-reader speech acceptance.
