# Wingy 0.31.0

- Independent Wingy crate namespace, based on Winit 0.31.0-beta.4 with the existing Glory maintenance fixes.
- Retains Android Activity recreation and GameTextInput fixes, and UIKit UITextInput support.
- Restores LICENSE, README and FEATURES links after the Windows directory rename. Archives are checked before uploading.
- Supersedes the initial beta dependency uploads whose archive link contents were incomplete. Published archives remain immutable.
- Reuses the verified, correctly packaged wingy-dpi 0.1.2 release. Platform packages and the Wingy facade are 0.31.0.
- Windows, Linux, AppKit/UIKit, Android NativeActivity/GameActivity, Web and Redox compilation gates remain in the release workflow; device acceptance is separate.
