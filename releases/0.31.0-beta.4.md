# Wingy 0.31.0-beta.4

First publication of the Glory-maintained winit fork under the `wingy` namespace.

- Retains the upstream 0.31.0-beta.4 version baseline and the existing Glory maintenance fixes.
- Renames active crates, Rust identifiers, examples and documentation to the new namespace.
- Keeps upstream copyright and license notices, and preserves upstream history.
- Uses registry dependencies between the renamed libraries; consumers need no global Cargo patches.
- `main` contains maintenance work; `upstream-main` is an exact mirror of rust-windowing/winit:master.

Validation and publication are gated by the repository CI. Platform checks establish compilation;
they do not by themselves claim real-device IME or accessibility acceptance.
